# 📊 Análise Comparativa de Desempenho Escolar no ENEM 2024

![Comparacao das Médias](imagens/media_escolas.png)

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de analisar e comparar o desempenho de escolas participantes do ENEM 2024 utilizando Python e a biblioteca Pandas.

A análise foi realizada a partir dos microdados do ENEM, comparando as médias das escolas **Quarup**, **Tecnosert** e **Magon** com a média geral nacional do exame.

O projeto contempla desde a importação e tratamento dos dados até a geração de gráficos para facilitar a interpretação dos resultados.

---

## 🎯 Objetivos

- Importar e tratar os dados do ENEM 2024.
- Calcular as médias das notas por disciplina.
- Comparar o desempenho das escolas selecionadas.
- Comparar os resultados com a média geral do ENEM.
- Gerar visualizações para apoiar a análise dos dados.
